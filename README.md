# KAIVIRO

Plateforme automobile intelligente open source : application mobile offline-first (Android d'abord), lecture OBD en lecture seule, moteur de diagnostic déterministe, IA hybride et Command Center d'administration privé.

> Nom de travail, non validé juridiquement (ADR-0013).
